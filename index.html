PhysioLink

● In Development Solo Developer 2025 – 2026
TypeFull-Stack App
PlatformMobile + API
StatusIn Development
Timeline2025 – 2026
Overview

PhysioLink is a full-stack physiotherapy clinic management platform built around two core products: a Flutter patient mobile app and an ASP.NET Core REST API backend. The system is architected for multi-tenancy, allowing multiple independent clinics to operate on a single deployment with complete data isolation between tenants. From appointment booking to exercise program delivery, every touchpoint is designed with the patient experience in mind.

Key Features
📅
Appointment Management
Patients book, reschedule, and view upcoming sessions directly from the mobile app
💪
Exercise Assignment
Physiotherapists build and assign custom exercise programs with instructions and repetition tracking
🏗️
Multi-Tenant Architecture
Clinic-level data isolation — each organization operates in a fully scoped environment
🔒
JWT Authentication
Secure token-based auth with role separation between patients, therapists, and admins
📱
Flutter Mobile App
Cross-platform patient app built with Riverpod state management and go_router navigation
🖥️
Admin Panel — Phase 2
Full clinic management dashboard covering staff, schedules, and patient records
ARCHITECTURE HIGHLIGHTS
  • Clean Architecture — Domain, Application, Infrastructure, and API layers fully separated
  • Repository Pattern with EF Core for abstracted, testable data access
  • Global Query Filters on tenant ID for seamless multi-tenant data scoping
  • Dependency Injection throughout — every service is composable and replaceable
  • LINQ-powered queries with proper pagination and filtering support
  • EF Core Migrations for versioned, reproducible schema management
Tech Stack
FlutterDart Riverpodgo_router FreezedASP.NET Core C#EF Core SQL ServerJWT Auth REST APIClean Architecture

Maqam

✓ Completed Solo Developer 2025
TypeWeb E-Commerce
PlatformWeb (MVC)
StatusCompleted
Timeline2025
Overview

Maqam (مقام — the Arabic word for musical mode) is a full-stack e-commerce platform for musical instruments. Built on ASP.NET Core MVC with a SQL Server backend, it delivers a complete end-to-end shopping experience: from discovering instruments by category, to managing a cart, placing an order, and fulfilling it through an admin panel. The project covers the full MVC lifecycle with clean separation of concerns, EF Core data access, and ASP.NET Identity for authentication.

Key Features
🛒
Shopping Cart
Real-time cart management — add, update quantities, and remove items with instant subtotal calculation
🏷️
Category Filtering
Browse the full instrument catalog or filter by type — guitars, keyboards, percussion, and more
👤
User Authentication
ASP.NET Identity with registration, login, and persistent sessions for returning customers
🔑
Role-Based Access
Separate Admin and Customer roles — admins access the management dashboard, customers the storefront
📦
Order Processing
Full order lifecycle from cart checkout to order confirmation and status tracking
🔧
Admin Dashboard
Manage products, categories, inventory, and orders from a dedicated admin interface
TECHNICAL HIGHLIGHTS
  • MVC Pattern — Controllers, Views, and Models fully decoupled
  • EF Core with SQL Server and schema migrations for version-controlled data
  • ASP.NET Identity for secure, production-grade authentication and authorization
  • Repository pattern for clean data access abstraction across the application
  • Bootstrap-based responsive layout — works across desktop and mobile browsers
  • CRUD operations for products and categories with input validation

Aman — أمان

✓ Completed Lead Designer 2024
TypeUI/UX Case Study
PlatformMobile (iOS/Android)
StatusCompleted
Timeline2024
Overview

Aman (أمان — "Safety" in Arabic) is a thoughtfully designed mobile application for women who have experienced abuse, assault, or trauma. The design process was entirely research-driven — no screens were designed until user interviews were conducted, personas were built, and competitive products were analyzed. The result is a calm, safe, and empowering digital space where users can process their experiences, find community, and access professional support.

Design Process
01
Research & Discovery
User interviews with target demographic, desk research on trauma-informed design, surveys to validate assumptions
02
Personas & Empathy Maps
3 detailed user personas capturing different user needs, emotional states, and usage contexts
03
Competitive Analysis
Evaluated 5+ existing mental health apps — identified gaps in safety features, Arabic language support, and trauma-specific flows
04
Information Architecture
Card sorting exercises to define navigation, user flows mapped for core journeys (journaling, booking, support circles)
05
Wireframes → High-Fidelity
Low-fidelity sketches iterated to polished high-fidelity screens with a calming rose & lavender visual language
06
Interactive Prototype
Fully clickable Figma prototype covering all core user flows — shared on Behance as a complete case study
App Features
📔
Private Journaling
Secure, encrypted mood-tracked journal entries — a space that belongs only to the user
🫂
Support Circles
Anonymous community groups organized by shared experience — peer connection without identity exposure
👩‍⚕️
Expert Consultations
Book private sessions with licensed psychologists and trauma-specialized counselors
🌅
Daily Positive Notes
Affirmations and healing exercises delivered daily — building emotional resilience over time
🆘
Crisis Resources
One-tap access to emergency contacts, crisis hotlines, and safety planning tools
🔐
Privacy-First Design
Discreet app icon, quick-exit button, and biometric lock — safety at the OS level
