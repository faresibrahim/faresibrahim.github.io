// Overview

Patient mobility, clinic clarity.

PhysioLink is a full-stack physiotherapy clinic management platform built around two core products: a Flutter patient mobile app and an ASP.NET Core REST API backend. The system is architected for multi-tenancy, allowing multiple independent clinics to operate on a single deployment with complete data isolation between tenants.

From appointment booking to exercise program delivery, every touchpoint is designed with the patient experience in mind. The Phase 2 admin panel will extend the same architecture into a full clinic management dashboard.

// Architecture Highlights
ENGINEERING DECISIONS
  • Clean Architecture — Domain, Application, Infrastructure, and API layers fully separated
  • Repository Pattern with EF Core for abstracted, testable data access
  • Global Query Filters on tenant ID for seamless multi-tenant data scoping
  • Dependency Injection throughout — every service is composable and replaceable
  • LINQ-powered queries with proper pagination and filtering support
  • EF Core Migrations for versioned, reproducible schema management
