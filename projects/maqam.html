// Overview

A store for the strings, keys, and skins.

Maqam (مقام — the Arabic word for musical mode) is a full-stack e-commerce platform for musical instruments. Built on ASP.NET Core MVC with a SQL Server backend, it delivers a complete end-to-end shopping experience: from discovering instruments by category, to managing a cart, placing an order, and fulfilling it through an admin panel.

The project covers the full MVC lifecycle with clean separation of concerns, EF Core data access, and ASP.NET Identity for authentication.

// Technical Highlights
ENGINEERING DECISIONS
  • MVC Pattern — Controllers, Views, and Models fully decoupled
  • EF Core with SQL Server and schema migrations for version-controlled data
  • ASP.NET Identity for secure, production-grade authentication and authorization
  • Repository pattern for clean data access abstraction across the application
  • Bootstrap-based responsive layout — works across desktop and mobile browsers
  • CRUD operations for products and categories with input validation
