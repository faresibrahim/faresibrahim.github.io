// Overview

Eyes, wheels, and a plan.

Finder Pal is an intelligent warehouse robot developed as the capstone project at the University of Michigan-Flint. The robot autonomously navigates warehouse aisles, identifies target items via an onboard camera using computer vision, and places them with precision at designated drop points.

I contributed to robot development, facilitated weekly team standups, and designed the team's project website from scratch using HTML, CSS, and JavaScript.

// Robot Capabilities
🧭
Autonomous Navigation
Real-time path planning with obstacle detection and avoidance in dynamic warehouse environments
👁️
Computer Vision
Onboard camera with image recognition to identify, locate, and classify target items on shelves
🎯
Precise Placement
Accurate item retrieval and deposit — the robot confirms placement before marking a task complete
⚡
Real-Time Processing
On-device computation for navigation and vision — no cloud dependency for core operations
