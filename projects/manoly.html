// Overview

Owning the warehouse, not renting it.

Manoly Warehouse (مخزن منولي) is a production inventory system I built from scratch for Manoly International Wood to replace their AppSheet setup. The driver was real: per-user licensing was getting expensive, the UI couldn't represent the warehouse the way the team actually thought about it, and data ownership was becoming a concern at their data scale.

The warehouse is physically organized into ~432 shelf and rack locations across rows A–F, holding roughly 421 products with shelf-level capacity rules that differ between traditional shelves (A/B/C, capped at 6 positions) and racks (D/E/F, up to 12). Every screen is Arabic-first with right-to-left layout.

A core part of the project is the Excel sync workflow: the client's warehouse state evolves through spreadsheets, so I built a Python + openpyxl pipeline that parses the layout, runs a three-strategy product matcher, and emits idempotent SQL with full audit tagging. The application runs on a clean domain model with rich entities, EF Core Fluent API mappings, and a custom "Warm Editorial" design system inspired by the company's logo.

// The Excel Sync Pipeline
PYTHON + OPENPYXL DATA PIPELINE
  • Parses the client's evolving Excel layout — handles shelf/rack structure, merged cells, and Arabic text
  • Runs a three-strategy product matcher — exact match, normalized match, and fuzzy match against the live DB
  • Emits idempotent SQL — every run can safely re-execute without creating duplicates or losing audit trails
  • Full audit tagging on each placement — source file, row number, and import timestamp baked in
  • Reconciliation report flags new products, missing placements, and capacity violations before commit
// Architecture Highlights
ENGINEERING DECISIONS
  • Domain-Driven Design — rich entities with private setters and factory methods enforcing invariants
  • EF Core Fluent API mappings — full control over schema, indexes, and relationships
  • DomainException middleware — business rule violations surface as localized Arabic UI messages
  • Custom design system tokens — Tailwind config built on the company logo's warm palette
  • Serilog structured logging across application, sync, and identity events
  • Containerized deployment — Docker image hosted on Fly.io with a managed PostgreSQL on Neon.tech
